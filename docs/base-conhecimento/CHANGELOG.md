# Changelog da base de conhecimento

Registro curto de **mudanças de comportamento** que alteraram esta base (mais recente primeiro). Uma linha por mudança: data, o que mudou, arquivos da base tocados.

Se uma alteração de código **não** afeta nenhuma feature, fluxo, regra de acesso, modelo de dados ou rota, registre mesmo assim com `sem impacto na base` (isso marca a revisão como feita).

- 2026-11-23: ficha D&D 5e: equipamento passa a ser lista de itens (`itens`), com peso total. Página: ficha-dnd5e.
- 2026-11-23: **Ficha de D&D 5e:** ficha automatizada por jogador (`mesas/{id}/personagens/{uid}`, regra nova), com rolagens mostradas como conta ("1d20 + 5 (Carisma)…"), ataques, espaços e lista de magias, descanso longo; só em mesas D&D 5e; menu "Minha ficha" (jogador) e "Fichas D&D" (mestre). Páginas: ficha-dnd5e (nova), README, permissoes-e-seguranca, arquitetura.
- 2026-11-23: **Sistema da mesa em dropdown:** sistemas públicos no banco (`sistemas`, leitura para logados) + sistemas pessoais por usuário (`sistemasPessoais`, privados), cadastráveis no wizard de nova mesa. Páginas: mesas-e-convites, permissoes-e-seguranca, arquitetura.
- 2026-11-23: **Timeline do mestre:** nova ferramenta (grupo Jogo, só mestre) com eventos num eixo numérico, ramos/ramificações, marcador "agora", zoom, minimapa, busca e exportar/importar; grava em `segredos/timeline` (sem regra nova) e é apagada com a mesa. Páginas: timeline (nova), README, arquitetura, permissoes-e-seguranca, glossario, navegacao-e-busca.
- 2026-11-23: especificação para recriar as Marcas de Pacto como extensão comum (`docs/planejamento/marcas-de-pacto-como-extensao.md`). Só planejamento; página tocada: extensoes (link em "O que ainda é plano").
- 2026-11-23: **E7 das extensões:** estado por escopo (`compartilhado`, `mestre`, `porJogador`, `doJogador`) em `extensoes/{extId}/estado/` com regras do Firestore, aprovado pelo mestre (`estadoAprovado`); `RPG.estado.*`, `RPG.eu`, `RPG.podeSalvar`; jogador grava o próprio `doJogador` sem aprovação; evento `estado.jogadorSalvou`; dados iniciais na biblioteca (`estadoInicial`); painel Dados (editar, limpar, backup/restaurar, aprovar escopos); ensaio com "Ver como" e estado em memória; `RPG.alterar`/`RPG.excluir` com `alterar:fichas`/`alterar:missoes`, antes → depois e desfazer que restaura; pedidos recusados automaticamente com `motivo`. Link quebrado para o plano antigo corrigido. Páginas: extensoes, criar-extensao, permissoes-e-seguranca, glossario.
- 2026-11-23: proposta OpenSpec `extensoes-estado-por-escopo` (E7: estado por escopo, escrita do jogador, alterar/excluir dados). Só planejamento, nada implementado: sem impacto na base.
